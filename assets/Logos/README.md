# Logos

Exported from the Figma brand guidelines (Areeba x magier client file, Logotype slides 6–10). Never redraw, recolour or stretch them.

| File | Use |
| --- | --- |
| `areeba-logo.svg` | Primary wordmark in Signal Red. Light, neutral backgrounds (White, Chalk). |
| `areeba-logo-chalk.svg` | Wordmark in Chalk. Dark or saturated backgrounds (Obsidian, Crimson Deep, photography). |
| `areeba-logo-contained.svg` | Wordmark inside a Signal Red container. Next to other brands' logos (partner strips, co-branding). |
| `areeba-logomark.svg` | The lowercase "a" alone. App icons, avatars and tight spaces where the wordmark won't fit. |

- Always lowercase. Clear space on every side equals the full height of the logo.
- The logo is the main place Signal Red appears. It is never used for buttons or status (see the Colour section of the brand book).
- `asterisk-*.svg` are the design system's own mark (areeba Asterisk 4), not the areeba logo; see the Logo section of the main README.
- No favicon yet: the favicon frames in Figma are empty placeholders. Use `areeba-logomark.svg` until official icons exist.
