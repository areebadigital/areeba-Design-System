# Balance

The balance at the top of a card or wallet screen, with a show/hide toggle.

- The eye button hides the amount (masked as ••••••, and announced as "Balance hidden"). Remember the choice per device.
- `amount` is a formatted string; it is isolated left-to-right so "$1,395.72" reads correctly in Arabic.
- One balance per screen. For several accounts, show each on its card.

From the areeba pay app, restyled to the system tokens.
