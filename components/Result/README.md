# Result

The last step of a flow: it worked, or it did not.

- `tone="success"` (default) or `"danger"`. Danger is announced immediately (`role="alert"`).
- Title says what happened ("Top up successful"); the body gives the facts that matter (amount, card) and, on failure, what to do.
- One action: "View receipt", "Try again". Close the flow from the header.

From the areeba pay app, restyled to the system tokens.
