# ServiceTile

A tile in a grid of services or categories: mobile recharge, bills, gift cards.

- A button (`onClick`) or link (`href`) with a mark, a name and one line of description. Put tiles in a `.ar-tiles` grid (2 per row on phones).
- The mark shows initials or an icon on a tinted square (`tone`: brand, info, success, warning). Do not paste third-party logos unless you have the right to use them.
- Group tiles under short headings; put search above the grid when there are more than ~8.

From the areeba pay app, restyled to the system tokens.
