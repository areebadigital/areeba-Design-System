# Avatar

A person or merchant: a photo, or initials on a tinted circle.

- Decorative by default, because the name sits next to it. Pass `label` when the avatar stands alone (it then announces the name).
- `size`: `sm` 32px in rows, `md` 48px in lists and recipients, `lg` 88px on profile headers.
- Initials are one or two letters in the person's script (RK, ر خ). Fall back to initials when a photo fails to load.
- `status` adds a small `success` dot for "can receive money" or online.

From the areeba pay app, restyled to the system tokens.
