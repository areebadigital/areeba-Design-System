# Badge

A small pill that labels status on transactions, accounts and records.

- Tones map to meaning: `success` completed/verified, `warning` pending/expiring, `danger` declined/failed, `info` neutral system states, `brand` new/promoted, `neutral` drafts and archived.
- Always a word, never colour alone. Use `dot` in lists to aid scanning.
- One or two words, sentence case. Not interactive; for filters use Tabs.
