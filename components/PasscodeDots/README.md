# PasscodeDots

Shows how many passcode digits are entered, above a NumberPad.

- Filled dots for digits entered; screen readers hear "4 of 6 digits entered" as it changes.
- `error` turns the dots `danger`, shakes them once (not with reduced motion) and announces the message: say how many tries are left.
- Never show the digits. After too many tries, lock and offer a reset (see the Passcode block).

From the areeba pay app, restyled to the system tokens.
