# CopyCode

A code to copy: a voucher code, a reference, an IBAN.

- Shows the code in IBM Plex Mono, left-to-right, with a Copy button that confirms "Copied" on screen and to screen readers.
- Group long codes in fours ("3FBV 953N DN71") so people can read them out. Copy the code as shown.
- If the clipboard is blocked the code stays selectable. Pair it with Share when people pass the code on.

From the areeba pay app, restyled to the system tokens.
