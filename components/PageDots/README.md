# PageDots

Where you are in a carousel: cards on the home screen, onboarding steps.

- Decorative for sighted users; screen readers hear "1 of 2". Let people swipe and also reach each item with a button or tab.
- The current dot is a wider `ink` bar; others are `line-strong`.
- Up to ~6 items; beyond that show "3 of 12" as text.

From the areeba pay app, restyled to the system tokens.
