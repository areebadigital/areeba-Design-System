# Colour

Every colour lives in `tokens.json` and reaches code as a CSS variable from `tokens.css` (`var(--brand)`). Light is the default theme; dark is set with `data-theme="dark"` on `<html>` or follows the system setting.

**Crimson acts, Signal Red signs.** `brand` (Crimson Deep) is the action colour: buttons, selection, checked controls. `accent` (Signal Red) is only the logo and highlighted words in headlines 24px and larger. In a money product bright red reads as an error, so it never marks an action or a status.

Each row shows the token in both themes and checks it against the surface it is used on: 4.5:1 for text, 3:1 for control borders, focus rings, chart marks and large text. Status colours always come with an icon or a word.
