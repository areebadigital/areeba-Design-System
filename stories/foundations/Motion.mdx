# Motion

Motion is quick and functional: it shows where something came from, confirms that a press landed, and never makes people wait. Every component animates with the same few tokens, so the whole system's feel changes in one place (`tokens.json` → `motion`).

## Tokens

| Token | Value | Use |
| --- | --- | --- |
| `--duration-instant` | 100ms | Hover, press, a checkbox tick, list rows |
| `--duration-fast` | 150ms | Switches, chips, field focus, colour changes |
| `--duration-base` | 250ms | Menus, popovers, toasts, tab panels, the passcode shake |
| `--duration-slow` | 400ms | Sheets, dialogs, the success check, meters filling |
| `--ease-standard` | cubic-bezier(0.2, 0, 0, 1) | Something moving or changing on screen |
| `--ease-enter` | cubic-bezier(0, 0, 0, 1) | Something arriving (decelerates) |
| `--ease-exit` | cubic-bezier(0.3, 0, 1, 1) | Something leaving (accelerates) |
| `--motion-distance` | 8px | How far menus, toasts and panels travel |

## Shared animations

`ar-fade-in`, `ar-rise-in` (toasts, file rows, notifications), `ar-drop-in` (menus, Select, DatePicker), `ar-scale-in` (dialogs), `ar-sheet-up` (bottom sheets), `ar-pop-in` (the Result check), `ar-tick-in` (checkbox tick) and `ar-shake` (a wrong passcode). They live in `src/styles/motion.css`.

## Rules

- **Enter, don't exit.** Things that arrive animate; things that leave disappear at once, so flows stay fast and nothing blocks the next tap.
- **Press feedback is small:** buttons scale to 0.98, icon and round buttons to 0.94, number pad keys to 0.96, for `--duration-instant`.
- **Only opacity and transform move**, plus colours and borders. Never animate layout (width, height, margins) except a meter or progress bar filling.
- **Reduced motion is automatic.** With the system setting "Reduce motion", every `--duration-*` becomes 0ms, so components need no checks of their own.
- **Tokens only.** `npm run check` fails if a component's CSS contains a raw `ms` value or `cubic-bezier()`.
- **Money moments stay calm.** No bouncing amounts, no confetti; the success check pops once.
- **Right-to-left:** sheets rise from the bottom and menus drop down in both directions; the shake moves both ways, so it reads the same.
