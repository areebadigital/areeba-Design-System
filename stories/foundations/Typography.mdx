# Typography

**Plus Jakarta Sans** for everything, Arial as the system fallback; **IBM Plex Sans Arabic** for Arabic; **IBM Plex Mono** for IDs and API keys. All ship as `woff2` files in `fonts/` (SIL Open Font License), declared with `@font-face` in `tokens.css`.

Plus Jakarta Sans has no Arabic letters, so the Arabic face only covers Arabic code points (`unicode-range`). One stack, `--font-sans`, sets Latin in Jakarta and Arabic in Plex, even within a line. Arabic is never letter-spaced: tracking breaks the joins between letters.
